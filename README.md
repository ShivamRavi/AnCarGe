# AnCarGe
DA **ULTIMATE** GAMIFIED TASK MANAGEMENT SYSTEM. HYBRID BETWEEN CONSOLE AND GUI

Requirements:
``` requriee
1. python 3
(Libraries)
i. tkinter
ii. threading
iii. json
iv. Pillow (PIL)
v. rich/curses/kivy (for next update)
```


Quick Start:
- Clone repo
- Quick start
  
Install dependencies: Pillow (PIL)

`pip install pillow`

Run the app:


`py -m arecarge.main`


## Features

- Uses threading to create a console and gui hybrid
- Customizable rewards for each task
- Envourages productivity

### boss battles
has boss battles for random items and coins
requires u to focus for some time to get random rewards


### upgardes. 
Non linear upgrade tree with many features and op things
neeeds coins and items form boss battles

### cool abilties

Has many really cool abiliteies, like bloodsteal greed maw etc/
